From file to paper

  1. 01Write pathsLines, circles and hatches in plain JavaScript or any SVG.
  2. 02Sort strokesPlotbot reorders them so the pen travels as little as possible.
  3. 03Pick a penFineliners from 0.3 to 0.8 mm. Swap mid-plot for a second weight.
  4. 04PlotHead down, ink on. A postcard takes about five minutes.

Changelog

  • v2.3.0
    New

    s.hatch() takes a side option, so only faces turned from the light get shaded.
