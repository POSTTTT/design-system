The design idea, step by step

Catch → Store
Send the roof's runoff through one filter before the tank.

A single first-flush filter sits between roof and tank, so debris never enters storage. The tank fills on the flow plane; nothing is controlled yet.

Store → Distribute
Add an overflow leg so a full tank never floods.

The control pen (dashed orange) branches off the filter to an overflow outlet. When the tank is full, excess routes away instead of backing up the flow path to the house.
