design principle
One pen for flow, one pen for control — never crossed.

Every connection carries a plane. The solid ink pen draws data; the dashed orange pen draws signalling. They run parallel, offset by a fixed perpendicular gap, so a dense diagram still reads at a glance — the same convention engineers already sketch by hand.
